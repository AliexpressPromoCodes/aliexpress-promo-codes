## AliExpress Black Friday FAQ

### When does the AliExpress Black Friday sale start and end?

The sale runs from **November 19 to December 4, 2026**. Black Friday is **November 27** and Cyber Monday is **November 30**.

### How do I use AliExpress Black Friday promo codes?

Choose an offer for your shipping country and order amount. Enter one code in the promo code field at checkout and confirm the discount appears before you pay.

### Can I use both codes on the same order?

No. The two codes on each line are alternatives for the same discount. Try the first one, then try the second if it doesn’t apply.

### Why isn’t my AliExpress coupon code working?

Check that your shipping country matches the offer, your eligible items meet the minimum spend, and the code isn’t restricted to first orders. The offer may also have expired or reached its redemption limit.

### Can I use AliExpress discount codes in my local currency?

Set your shipping country and currency before checking the offer. The same Global code pairs appear across the regional sections, but discount amounts and minimum orders vary by currency. Check the final amount at checkout.

### Are there separate promo codes for new users?

Yes. The Global and regional new-user offers apply to eligible first orders during the sale. The separate USA first-order codes are valid until **December 31, 2026**.
